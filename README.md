
# JSON Compare Tool

A free online JSON Compare Tool for comparing two JSON objects,
JSON files, and API responses.

## 🚀 Live Demo

👉 https://comparejson.org/

## ✨ Features

- Compare two JSON documents
- Side-by-side comparison
- Added, removed, and modified values
- Word-level difference highlighting
- Nested JSON comparison
- Array comparison
- JSON formatting
- JSON validation
- Large JSON support
- Browser-based comparison
- No installation required


## 🔧 How It Works

Paste your original JSON on the left and your updated JSON
on the right.

Click **Compare JSON** to see the differences.

## 💻 Example

### Original JSON

```json
{
  "name": "John",
  "age": 30,
  "city": "Surat"
}

### Updated JSON
{
  "name": "John",
  "age": 31,
  "city": "Ahmedabad"
}
