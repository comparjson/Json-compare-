# JSON Compare Tool

A free online **JSON Compare Tool** for comparing JSON objects, JSON files, and API responses. Quickly find added, removed, and modified values with a clear side-by-side comparison.

## 🚀 Live Demo

**Try JSON Compare Online:**

https://comparejson.org/

## ✨ Features

* Compare two JSON objects
* Compare JSON files
* Side-by-side JSON comparison
* Highlight added values
* Highlight removed values
* Highlight modified values
* Word-level difference highlighting
* Nested JSON comparison
* JSON array comparison
* JSON formatting
* JSON validation
* Large JSON support
* Browser-based tool
* No installation required

## 📖 How to Use

1. Open the [JSON Compare Tool](https://comparejson.org/).
2. Paste the original JSON into the left editor.
3. Paste the updated JSON into the right editor.
4. Click **Compare JSON**.
5. Review the highlighted differences.

## 💡 Example

### Original JSON

```json
{
  "name": "John",
  "age": 30,
  "city": "Surat"
}
```

### Updated JSON

```json
{
  "name": "John",
  "age": 31,
  "city": "Ahmedabad"
}
```

### Differences

The comparison identifies changes such as:

* `age`: `30` → `31`
* `city`: `"Surat"` → `"Ahmedabad"`
